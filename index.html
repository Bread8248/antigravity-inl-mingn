View on Vibe Coding

vibe_coding.md

I think vibe coding is a great concept but it's not always practical. AI can help build applications or websites fast, but it doesn't always meet the requirements of the user. I think it's best to use AI as a tool to help you build the ground for applications or websites, but use your own brain to actually make sure they are secure, meet demands, changes are documented and the code is efficient.

It's important to be able to adapt and use the newest technologies to stay competetive, but also know the risks that could come with it.
